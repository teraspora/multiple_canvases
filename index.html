Help

Press a digit key (1 to 9) to change the canvas count (square of the digit, e.g. press 4 → 16 canvases).

  • c - toggle curve info display
  • d - toggle debug mode and reset canvas count to default
  • h - show this help panel
  • a - create just Atom scenes
  • u - create just Curve scenes
  • v - create just Video scenes
  • r - create just Random scenes
